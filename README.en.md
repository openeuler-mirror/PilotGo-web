# PilotGo-web

#### Description
PilotGo-web is the web frontend for PilotGo.

Note: The frontend of the **PilotGo** project uses vue2 components, which will stop being maintained on December 31, 2023. Therefore, the frontend of the PilotGo project needs to be migrated to vue3 components. This branch is used to host the related code.
